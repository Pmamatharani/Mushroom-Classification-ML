
# Mushroom Classification using Machine Learning

## Project Description
This project uses Machine Learning to classify mushrooms into two categories:
- Edible
- Poisonous

## Dataset
UCI Mushroom Dataset

- Total Records: 8124
- Total Features: 22
- Target Classes: Edible and Poisonous

## Algorithm
Decision Tree Classifier

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Process
1. Dataset Loading
2. Data Preprocessing
3. Feature Encoding
4. Train-Test Splitting
5. Model Training
6. Prediction
7. Model Evaluation

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the Python file:

python mushroom_classification.py

## Note
This project is for educational purposes only.
Never use its predictions to decide whether a real mushroom is safe to eat.
